# The Shape of Wealth — Die Form des Reichtums

Interactive visualization of global wealth distribution: a wealth-density curve over the
world population, with continuous scroll/drag zoom on both axes — from the full population
down to the richest individuals on Earth (spike ≈ $865 B). Bilingual DE/EN.

**Live:** https://the-shape-of-wealth.w4c.ch

## Tech

- Single standalone `index.html` — inline CSS/SVG/JS, no build step, no dependencies
- Self-hosted Unbounded font (local woff2) — zero external requests
- Zoom: scroll wheel or drag on the population axis (bottom) and wealth axis (left)
